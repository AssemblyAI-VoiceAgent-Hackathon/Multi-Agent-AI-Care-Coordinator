RUN WITH VS CODE + LIVE SERVER
1. Extract CareCoordinator_Frontend.zip.
2. Open VS Code.
3. Select File > Open Folder and choose the CareCoordinator_Frontend folder.
4. In the Explorer, open index.html.
5. If Live Server is not installed, open Extensions (Ctrl+Shift+X), search for "Live Server" by Ritwick Dey, and install it.
6. Right-click index.html and select "Open with Live Server".
7. Your browser should open the landing page, typically at http://127.0.0.1:5500/index.html.
8. Use Get Started / Sign In to navigate through the pages. You can also open login.html, signup.html, patient-dashboard.html, and admin-dashboard.html directly.

IMPORTANT LIMITATIONS
- This is a frontend-only prototype. File upload is simulated in the browser; no file is sent to a server.
- AI summaries and question answers are static/sample demo responses, not generated by an AI model.
- Admin GPU, memory, response-time, token-speed, agent, and verification values are simulated.
- Demo accounts are stored in browser localStorage. Passwords are SHA-256 hashed in the browser for this prototype, but client-side hashing and localStorage are NOT secure authentication. Do not use real passwords or sensitive information.
- A production application requires a secure backend, server-side authentication and authorization, secure session management, encrypted storage, real document processing, audit logs, privacy/security review, and clinician validation.
- This is not a medical device, not a clinical decision system, and not for emergencies.
