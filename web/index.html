Synthetic data only. This tool organizes what is written in the records. It does not diagnose or give medical advice. In an emergency, call your local emergency number.
What is real in this prototype?
  • Working now: reading uploaded PDFs, the 6 agents, emergency hard stop, source links for every statement, verification with 2 retries, flags for the clinician, approve / improve / reject.
  • Not connected yet: the AI model on the AMD GPU. Until it is connected, the agents run on fixed Python rules. The badge at the top right shows which mode is on.
  • GPU numbers are shown only when a real AMD GPU is connected. They are never simulated.
  • Medicine checks use a small demo drug list, not a licensed clinical database. Anything not on it says "cannot confirm".
  • All records are synthetic (made with Synthea). No real patient data.
